# Agile Retrospective
## Project: Student Task Manager

### 1. What Went Well?
- Successfully developed a Student Task Manager website.
- HTML, CSS and JavaScript were integrated.
- GitHub repository was created successfully.
- CI workflow automatically checked project files.
- CD workflow successfully deployed the website.
- The website is accessible through GitHub Pages.

### 2. What Could Be Improved?
- Improve the website design and user interface.
- Add more task management features.
- Improve error handling.
- Add automated website testing.

### 3. Action Items
- Add task editing functionality.
- Improve mobile responsiveness.
- Implement automated testing.
- Continue improving the website based on feedback.

### 4. Conclusion
The project helped us understand CI/CD workflows
using GitHub Actions and the importance of Agile
Retrospectives for continuous improvement.
